 5. Reflection

 Did AI Help or Hinder Understanding?

Helped significantly. The AI accelerated boilerplate writing (CRUD routes, CSS, form components) allowing focus on higher-level architecture decisions. For areas like the SVG donut chart math (stroke-dasharray calculations) and SQL JOIN aggregation for stats, the AI explained its reasoning which deepened understanding.

 Issues Encountered Integrating AI Output

1. Native module incompatibility — AI initially suggested `better-sqlite3` which failed on Node v25. After describing the error, the AI correctly identified the issue and proposed `node:sqlite`. This required understanding the Node.js built-in module system.

2. API shape mismatches — The frontend `AllTasks` page fetches all tasks from all projects. The AI's first approach used a non-existent endpoint. Debugging required reading the actual backend routes and adapting the frontend to use parallel requests per project.

3. CSS specificity conflicts — Some modal styles clashed with page-level styles. Resolved by manually scoping selectors.

 What Was Learned from Debugging AI-Generated Code

- Always read generated SQL queries — The COALESCE UPDATE pattern works but needs understanding to verify correctness.
- Test API contracts independently — Used `curl` to verify backend responses before connecting the frontend.
- Node.js ecosystem knowledge matters — Understanding why `better-sqlite3` fails (C++ standard mismatch) required knowing how native addons work.
- AI is best for structure, humans for correctness — The AI generated correct structure 90% of the time, but edge cases (null handling, BigInt, empty states) needed human attention.

 Benefits of AI-Assisted Development

- Speed: ~70% faster than writing everything manually.
- Consistency: AI maintained consistent patterns (CSS variables, validation middleware shape) across files.
- Documentation: Swagger JSDoc comments generated accurately from route structure.

 Limitations

- AI cannot run the code itself, so compilation/runtime errors must be caught by the developer.
- Generated CSS sometimes too verbose — required manual pruning.
- AI may suggest deprecated packages (like older versions of libraries).
